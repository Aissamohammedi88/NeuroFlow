## 🚀 Présentation

Nexus Live AI est une interface de conversation IA entièrement fonctionnelle avec :
- Backend HTTP + Server-Sent Events (SSE) pour le streaming
- Frontend Three.js avec scène 3D immersive
- Gestion de sessions persistantes (JSONL + SQLite)
- Moteur de réponse basé sur règles + heuristiques
- Monitoring système en temps réel
- API REST complète
- Interface CLI pour chat, statistiques et sessions
- Export Markdown/JSON
- Recherche plein texte dans l'historique
- Rate limiting et authentification par token
- Compression gzip et support CORS
- Hooks plugins extensibles
- Sauvegarde automatique
- Multi-langues (FR/EN)
- Thème dynamique personnalisable
